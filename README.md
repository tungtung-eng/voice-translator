# 隨身翻譯

手機網頁 App：用說的或拍照，把**繁體中文**和對方的語言互相翻譯。字大、按鈕大，長輩也好用。

支援語言：英文、日文、韓文、越南文、泰文、印尼文

## 功能

- **說話翻譯**：綠色按鈕說中文 → 翻成對方語言並唸出來；藍色按鈕讓對方說話 → 翻成中文並唸出來
- **自動對話**：按「🔁 自動對話」後不用再按按鈕。一方說完停頓一下就自動翻譯並唸出來，接著自動換聽另一方。想連續說話時，按自己那邊的按鈕就能換回來。（瀏覽器的免費語音辨識一次只能聽一種語言，所以是兩邊輪流）
- **放大給對方看**：翻譯結果全螢幕大字顯示，可以翻轉 180° 給坐在對面的人看
- **拍照翻譯**：拍菜單、路標、說明書，文字辨識後翻成中文，可以唸中文或原文
- **打字**：瀏覽器不支援語音時，可以改用打字
- **對話紀錄**：保存在手機上，可以清除
- **設定**：自動朗讀、慢速朗讀、更大字體
- 可以「加到主畫面」當 App 用

## 全部免費

| 功能 | 使用的服務 |
|---|---|
| 語音辨識 | 瀏覽器內建（Web Speech API） |
| 朗讀 | 瀏覽器內建（speechSynthesis） |
| 翻譯 | Google 翻譯免費公開端點；失敗時自動改用 MyMemory 免費 API |
| 拍照文字辨識 | [Tesseract.js](https://github.com/naptha/tesseract.js)，在手機上執行 |

注意：
- 翻譯需要網路。Google 免費端點不是官方 API，量大時可能被限制，會自動改用 MyMemory（每天約 5000 字免費額度）。
- 拍照翻譯第一次用某個語言時，要下載約 10–20 MB 的辨識資料，之後會快取。
- 語音辨識建議用 **Android 的 Chrome** 或 **iPhone 的 Safari**（iPhone 需開啟「設定 → Siri」中的聽寫/Siri）。Firefox 不支援語音，可用打字。
- 麥克風和相機需要 **HTTPS** 網址才能使用。

## 放到網路上（GitHub Pages）

1. 到 repo 的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`
4. 用手機打開網址 → 分享 → **加入主畫面**

## 本機測試

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```

## 檔案

- `index.html` 畫面
- `style.css` 樣式（大字、大按鈕）
- `app.js` 語音、翻譯、拍照辨識
- `sw.js`、`manifest.webmanifest` 讓它可以加到主畫面
